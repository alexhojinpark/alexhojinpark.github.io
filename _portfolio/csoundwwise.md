## Abstract

Integrating programmable audio languages with game audio middleware remains a challenging but promising area of research. This thesis explores that intersection by developing a plugin that embeds the Csound engine into Audiokinetic's Wwise platform. The project contributes both a technical solution, covering architecture, parameter control, and resource management, and a conceptual framework for real-time synthesis in game audio middleware.
